文章保存到 `src/content/posts/` 下，使用 `.md` 文件。文件开头填写 Front Matter，正文标题从 `##` 开始。

## Front Matter

```yaml
---
title: "文章标题"
published: 2026-10-03
description: 用一句话概括文章内容。
tags:
  - Blog
draft: true
hidden: false
pin: 0
toc: true
lang: zh
abbrlink: article-slug
---
```

| 字段 | 说明 |
| --- | --- |
| `title` | 必填，文章标题 |
| `published` | 必填，发布日期，格式为 `YYYY-MM-DD` |
| `description` | 可选，简短摘要；省略时自动提取正文 |
| `updated` | 可选，更新日期，格式为 `YYYY-MM-DD` |
| `tags` | 标签列表，按从宽到窄组成分类路径 |
| `draft` | `true` 为草稿，`false` 为公开；默认 `false` |
| `hidden` | `true` 为隐藏，不生成公开页面；默认 `false` |
| `pin` | 整数 `0–99`，默认 `0`；数值越大，置顶优先级越高 |
| `toc` | 是否显示章节目录 |
| `lang` | 文章语言，中文为 `zh` |
| `abbrlink` | 小写字母、数字、连字符组成的唯一短链接，例如 `spring-notes` |

标签顺序表示分类层级，同标签文章会自动显示在文章页右侧。

`abbrlink: spring-notes` 对应 `/posts/spring-notes/`，同一语言下的短链接不能重复。

## 图片、摄影参数与 Live

图片和视频使用腾讯云 COS 的 HTTPS 链接。以下 `example.com` 为示例地址，使用时替换为实际链接。

### 普通图片

图片单独成段。`alt` 会显示为图注；以 `_` 开头可保留替代文本并隐藏图注。

```markdown
![系统结构图](https://example.com/diagram.webp)

![_系统结构图](https://example.com/diagram.webp)
```

### 带参数的照片

使用单行 `::photo{...}`。点击照片可放大，已有摄影参数直接展示在图片下方。

```markdown
::photo{src="https://example.com/photo.webp" title="湖边" width="1600" height="1200" camera="Sony ILCE-7M4" lens="FE 35mm F1.8" focalLength="35 mm" aperture="ƒ/2.8" shutter="1/250 s" iso="ISO 100" exposure="0 EV"}
```

| 属性 | 写法 |
| --- | --- |
| `src` | 必填，有效 HTTPS 图片链接 |
| `width`、`height` | 实际像素尺寸，正整数，最大 `20000`；未知时省略 |
| `title` | 可选，简短替代文本与图注；不需要图注时省略 |
| `camera`、`lens` | 相机型号、镜头型号 |
| `focalLength`、`aperture` | 焦距、光圈，例如 `35 mm`、`ƒ/2.8` |
| `shutter`、`iso`、`exposure` | 快门、感光度、曝光补偿，例如 `1/250 s`、`ISO 100`、`0 EV` |
| `taken`、`location` | 可选，实际拍摄日期与地点，例如 `2026-10-03`、`杭州` |
| `live` | 可选，与照片配对的 HTTPS 视频链接 |

摄影参数和尺寸填写实际值，缺项可省略。

属性名区分大小写，属性值用双引号包裹，整条指令写在同一行。

### 多图分组

将照片指令放进 `:::photos`，每条指令之间留空行。照片按画幅排列，横竖图保留完整画面。

```markdown
:::photos{columns="2"}

::photo{src="https://example.com/landscape.webp" width="1600" height="1200"}

::photo{src="https://example.com/portrait.webp" width="1200" height="1600"}

:::
```

`columns` 推荐 `2`、`3` 或 `4`，省略时为 `4`；窄屏会调整布局。普通图片需要水平滚动画廊时可使用：

```markdown
:::gallery

![_远山](https://example.com/mountain.webp)

![_湖面](https://example.com/lake.webp)

:::
```

### Live 照片

在照片指令中增加 `live`，填写与照片配对的视频链接。视频使用浏览器支持的 MP4。

```markdown
::photo{src="https://example.com/photo.webp" width="1600" height="1200" live="https://example.com/photo-live.mp4" camera="iPhone 15 Pro"}
```

默认显示静态照片，点击 **LIVE** 图标播放，再次点击暂停。

### 关联独立相册

通过相册标识链接到已创建的独立相册：

```markdown
[查看完整相册](/gallery/album-slug/)
```

## 提示、折叠与代码

提示块支持 `note`、`tip`、`important`、`warning`、`caution` 五种类型，可自定义标题：

```markdown
:::tip[使用建议]

先运行最小示例，再扩展到实际业务。

:::
```

也可以使用 GitHub 风格：

```markdown
> [!WARNING]
> 执行前确认目标目录。
```

详细推导、补充步骤使用折叠块，方括号中的标题不能为空：

```markdown
:::fold[查看完整推导]

这里写补充内容，可包含列表、公式和代码。

:::
```

代码围栏标注语言名，例如 `ts`、`go`、`bash`。代码块自动提供语法高亮和复制按钮，超过 20 行时自动折叠。

````markdown
```ts
const message: string = 'Hello'
console.log(message)
```
````

容器必须以独立一行的 `:::` 结束。需要嵌套容器时，外层改用四个冒号 `::::` 开始和结束。

## 公式、图表与嵌入

### 数学公式

本博客的行内公式使用双美元符号，单个 `$` 不会触发公式渲染。块级公式将分隔符各放一行：

```markdown
能量满足 $$E = mc^2$$。

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Mermaid 图表

使用 `mermaid` 代码块生成流程图等图表，中文标签用引号包裹：

````markdown
```mermaid
flowchart LR
  A["输入"] --> B["处理"] --> C["输出"]
```
````

### 外部内容

以下指令各占一行，填写对应的仓库名称、视频 ID 或平台链接。

| 内容 | Markdown 写法 |
| --- | --- |
| GitHub 仓库 | `::github{repo="owner/repo"}` |
| YouTube 视频 | `::youtube{id="video-id"}` |
| Bilibili 视频 | `::bilibili{id="BV号"}` |
| Spotify | `::spotify{url="https://open.spotify.com/track/实际ID"}` |
| X 推文 | `::tweet{url="https://x.com/用户名/status/实际ID"}` |
| CodePen | `::codepen{url="https://codepen.io/用户名/pen/实际ID"}` |

## 完整文章示例

````markdown
---
title: "数据处理流程"
published: 2026-10-03
description: 一个读取、校验和输出数据的简单示例。
tags: []
draft: true
toc: true
lang: zh
abbrlink: data-processing
---

数据处理分为读取、校验和输出三个步骤。

## 流程

```mermaid
flowchart LR
  A["读取"] --> B["校验"] --> C["输出"]
```

## 示例

```ts
const values = [1, 2, 3]
const result = values.map(value => value * 2)
console.log(result)
```

:::tip[输入校验]

处理前检查数据类型和取值范围。

:::
````
