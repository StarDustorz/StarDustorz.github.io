在 `src/content/posts/` 下新建 `.md` 文件。开头写 Front Matter，正文标题从 `##` 开始。

## Front Matter

```yaml
---
title: "文章标题"
published: 2026-10-03
description: 用一句话概括文章内容。
tags:
  - Blog
draft: true
hidden: false
pin: 0
toc: true
lang: zh
abbrlink: article-slug
---
```

| 字段 | 说明 |
| --- | --- |
| `title` | 必填，文章标题 |
| `published` | 必填，发布日期，格式为 `YYYY-MM-DD` |
| `description` | 可选摘要；省略时从正文自动提取 |
| `updated` | 可选，更新日期，格式为 `YYYY-MM-DD` |
| `tags` | 标签列表，顺序从宽到窄，组成分类路径 |
| `draft` | 草稿设为 `true`，公开设为 `false`；默认 `false` |
| `hidden` | 设为 `true` 时隐藏文章，不生成公开页面；默认 `false` |
| `pin` | 整数 `0–99`，默认 `0`；数值越大，置顶优先级越高 |
| `toc` | 控制章节目录是否显示 |
| `lang` | 文章语言，中文为 `zh` |
| `abbrlink` | 唯一短链接，只用小写字母、数字和连字符，例如 `spring-notes` |

标签按顺序组成分类层级。文章页右侧会自动列出同标签的其他文章。

`abbrlink: spring-notes` 对应 `/posts/spring-notes/`，同一语言下的短链接不能重复。

## 图片、摄影参数与 Live

图片和视频填写腾讯云 COS 的 HTTPS 链接。示例中的 `example.com` 需要换成实际地址。

### 普通图片

每张图片单独一段。`alt` 会显示为图注；以 `_` 开头时保留替代文本，隐藏图注。

```markdown
![系统结构图](https://example.com/diagram.webp)

![_系统结构图](https://example.com/diagram.webp)
```

### 带参数的照片

用 `::photo{...}` 插入照片。点击照片可放大，摄影参数会显示在图片下方。

```markdown
::photo{src="https://example.com/photo.webp" title="湖边" width="1600" height="1200" camera="Sony ILCE-7M4" lens="FE 35mm F1.8" focalLength="35 mm" aperture="ƒ/2.8" shutter="1/250 s" iso="ISO 100" exposure="0 EV"}
```

| 属性 | 写法 |
| --- | --- |
| `src` | 必填，有效 HTTPS 图片链接 |
| `width`、`height` | 实际像素尺寸，正整数，最大 `20000`；未知时省略 |
| `title` | 可选的替代文本和图注；不需要图注时省略 |
| `camera`、`lens` | 相机型号、镜头型号 |
| `focalLength`、`aperture` | 焦距、光圈，例如 `35 mm`、`ƒ/2.8` |
| `shutter`、`iso`、`exposure` | 快门、感光度、曝光补偿，例如 `1/250 s`、`ISO 100`、`0 EV` |
| `taken`、`location` | 可选的拍摄日期和地点，例如 `2026-10-03`、`杭州` |
| `live` | 可选，与照片配对的 HTTPS 视频链接 |

填写实际尺寸和摄影参数，缺少的信息直接省略。属性名区分大小写，值用双引号包裹，整条指令写在同一行。

### 多图分组

把照片指令放进 `:::photos`，每条指令之间留空行。照片按画幅排列，横图和竖图都保留完整画面。

```markdown
:::photos{columns="2"}

::photo{src="https://example.com/landscape.webp" width="1600" height="1200"}

::photo{src="https://example.com/portrait.webp" width="1200" height="1600"}

:::
```

`columns` 推荐填 `2`、`3` 或 `4`，省略时为 `4`。窄屏会自动调整布局。普通图片也可以组成水平滚动画廊：

```markdown
:::gallery

![_远山](https://example.com/mountain.webp)

![_湖面](https://example.com/lake.webp)

:::
```

### Live 照片

给照片添加 `live` 属性，填写配对视频的链接。视频使用浏览器支持的 MP4。

```markdown
::photo{src="https://example.com/photo.webp" width="1600" height="1200" live="https://example.com/photo-live.mp4" camera="iPhone 15 Pro"}
```

默认显示静态照片。点击照片上的 LIVE 图标播放，再次点击暂停。

### 关联独立相册

独立相册按相册标识链接：

```markdown
[查看完整相册](/gallery/album-slug/)
```

## 提示、折叠与代码

提示块有 `note`、`tip`、`important`、`warning`、`caution` 五种类型，方括号内填写自定义标题：

```markdown
:::tip[使用建议]

先运行最小示例，再扩展到实际业务。

:::
```

也可以写成 GitHub 风格的提示：

```markdown
> [!WARNING]
> 执行前确认目标目录。
```

详细推导或补充步骤放进折叠块，方括号中的标题不能为空：

```markdown
:::fold[查看完整推导]

这里写补充内容，可包含列表、公式和代码。

:::
```

代码围栏填写语言名，如 `ts`、`go`、`bash`。代码块自带语法高亮和复制按钮，超过 20 行时自动折叠。

````markdown
```ts
const message: string = 'Hello'
console.log(message)
```
````

容器以单独一行的 `:::` 结束。嵌套容器时，外层用四个冒号 `::::` 开始和结束。

## 公式、图表与嵌入

### 数学公式

行内公式用双美元符号，单个 `$` 不会触发公式渲染。块级公式的两个分隔符各占一行：

```markdown
能量满足 $$E = mc^2$$。

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### Mermaid 图表

流程图等图表写在 `mermaid` 代码块中，中文标签用引号包裹：

````markdown
```mermaid
flowchart LR
  A["输入"] --> B["处理"] --> C["输出"]
```
````

### 外部内容

每条指令独占一行，参数填写对应的仓库名称、视频 ID 或平台链接。

| 内容 | Markdown 写法 |
| --- | --- |
| GitHub 仓库 | `::github{repo="owner/repo"}` |
| YouTube 视频 | `::youtube{id="video-id"}` |
| Bilibili 视频 | `::bilibili{id="BV号"}` |
| Spotify | `::spotify{url="https://open.spotify.com/track/实际ID"}` |
| X 推文 | `::tweet{url="https://x.com/用户名/status/实际ID"}` |
| CodePen | `::codepen{url="https://codepen.io/用户名/pen/实际ID"}` |

## 完整文章示例

````markdown
---
title: "数据处理流程"
published: 2026-10-03
description: 一个读取、校验和输出数据的简单示例。
tags: []
draft: true
toc: true
lang: zh
abbrlink: data-processing
---

数据处理分为读取、校验和输出三个步骤。

## 流程

```mermaid
flowchart LR
  A["读取"] --> B["校验"] --> C["输出"]
```

## 示例

```ts
const values = [1, 2, 3]
const result = values.map(value => value * 2)
console.log(result)
```

:::tip[输入校验]

处理前检查数据类型和取值范围。

:::
````
